# Security

Sema runs on your own machine and serves the API on `localhost`. Treat it as a local tool: don't expose port 8123 to a network you don't trust.

Report a vulnerability privately through [GitHub security advisories](https://github.com/A12N4V/sema/security/advisories/new), not in a public issue. Include the commit, the steps, and what an attacker gains. You'll get a reply within a week.
