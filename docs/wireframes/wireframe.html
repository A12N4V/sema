EEGvis

A Bloomberg-style terminal for EEG. Every recording opens as one dense, linked workspace — waveform, 3D scalp field, spectra and ICA all driven by a shared time cursor — and it's a drop-in web UI for MNE-Python, launched from a notebook or the CLI.
These frames redraw the working backend (M0–M4) and reframe the front end as a tiled terminal. New elements are tagged PROPOSED; unresolved calls OPEN Q.

EEGvisDesign Language & the MNE Bridgep.2 / 10

Terminal aesthetic

Absolute-black (#000 / panel #0A0A0C), 1px seams, one blue accent (#4FB0FF) + one amber for alerts. Data set in a mono face; labels in the UI face. Density over whitespace: a panel shows numbers, not captions. Every panel has a 16px header strip (title · source · sync-lock · pop-out) and nothing else chrome-wise.

Motion
Framer Motion, 90–200ms, easing [0.22,1,0.36,1]. The cursor line and panel data update every frame with no re-mount. Docking/solo animate; data never "loads" with a spinner — stale tiles dim to 60% until the fetch returns.

Notes & decisions

Built: two links hitting /export/raw.fif and /export/epochs.fif that stream the mutated MNE object, with a one-liner that downloads reflect every step so far. This page proposes: the ledger, revert, and five more export targets — chief among them runnable Python.

Provenance ledger. PROPOSED every mutating call appends {op, params, ts} server-side (/history). It's the audit trail, the summary, and the source for the .py export — one structure, many outputs.
Revert. OPEN Q in-place mutation has no undo. Re-run the recorded ledger from the original Raw up to step N (cheap-ish, deterministic) vs snapshot per step (fast, memory-heavy). Lean re-run.
